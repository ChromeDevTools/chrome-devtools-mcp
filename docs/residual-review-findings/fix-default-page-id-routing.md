## Fixed during review (not residual — included for context)

- **P0** `evaluate_script`'s independent `pageId` resolution (`src/tools/script.ts`) called
  `context.getPageById(pageId)` with no guard for `pageId === undefined`, so any normal
  `evaluate_script` call omitting `pageId` would throw `'No page found'` once
  `experimentalPageIdRouting` defaulted to `true`. Fixed with a `typeof pageId === 'number'`
  guard, mirroring `src/ToolHandler.ts`'s existing pattern. Caught independently by both the
  `correctness` and `api-contract` reviewers.
- **P1** `evaluate_script` didn't respect `--slim` — it only gated on
  `cliArgs?.experimentalPageIdRouting`, not `!cliArgs?.slim`, so `pageId` stayed exposed/honored
  there even in slim mode, unlike every other page-scoped tool. Fixed by adding the `!cliArgs?.slim`
  check to both the schema and resolution branches. Caught by the `testing` reviewer.

## Residual (not fixed in this PR)
